# Qontinui DOM Capture Extension (Deprecated)

> **This extension has been superseded by the UI Bridge SDK.**
>
> Instead of installing a browser extension, integrate the UI Bridge SDK directly into your application. The SDK provides richer element data, fingerprinting, and automated state machine construction — capabilities that aren't possible through a browser extension.

## Migrating to the UI Bridge SDK

1. Install the SDK in your application
2. Open the **Inspector** page in qontinui-runner
3. Click **Scan** to discover SDK-integrated apps on your network
4. Click an app to connect and inspect elements

See the [UI Bridge SDK documentation](https://github.com/qontinui/qontinui-runner) for integration instructions.

## Legacy Extension

The extension source code remains in this directory for reference. It is no longer published or supported.
