# Progress Components

## Overview

The progress component system provides consistent, accessible progress indicators across the qontinui-runner application. All components share a unified design language with semantic colors, smooth animations, and proper accessibility attributes.

## Components

### ProgressBar

The main progress bar component with full feature support.

```tsx
import { ProgressBar } from "@/components/ui/ProgressBar";

// Basic usage
<ProgressBar current={50} total={100} />

// With label
<ProgressBar
  current={50}
  total={100}
  showLabel
  labelFormat="count"
/>

// Indeterminate mode
<ProgressBar current={42} indeterminate />
```

#### Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `current` | `number` | Required | Current progress value |
| `total` | `number \| null` | `undefined` | Total value (null for indeterminate) |
| `progressType` | `ProgressType` | `"default"` | Color scheme |
| `status` | `ProgressStatus` | Auto-detected | Override status |
| `indeterminate` | `boolean` | `false` | Force indeterminate mode |
| `showLabel` | `boolean` | `false` | Show label text |
| `labelFormat` | `LabelFormat` | `"count"` | Label format |
| `label` | `string` | Auto-generated | Custom label text |
| `description` | `string` | `undefined` | Description below bar |
| `size` | `"xs" \| "sm" \| "md" \| "lg"` | `"md"` | Size variant |
| `ariaLabel` | `string` | Auto-generated | Custom ARIA label |

### InlineProgressBar

Compact variant for tables and lists.

```tsx
import { InlineProgressBar } from "@/components/ui/ProgressBar";

<InlineProgressBar
  current={5}
  total={10}
  progressType="file_progress"
/>
```

#### Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `current` | `number` | Required | Current progress value |
| `total` | `number \| null` | Required | Total value (null for indeterminate) |
| `progressType` | `ProgressType` | `"default"` | Color scheme |
| `className` | `string` | `undefined` | Additional CSS classes |

### StepProgressIndicator

Simplified indicator for step/workflow progress.

```tsx
import { StepProgressIndicator } from "@/components/active-dashboard/widgets/shared/StepProgressMarker";

<StepProgressIndicator
  current={5}
  total={10}
  type="test_progress"
/>
```

## Progress Types

Progress types determine the semantic color of the progress bar:

| Type | Color | Use Case |
|------|-------|----------|
| `default` | Blue | General progress |
| `file_progress` | Blue | File operations |
| `test_progress` | Purple | Test execution |
| `analysis_progress` | Cyan | Code analysis |
| `review_progress` | Amber | Review items |
| `iteration_progress` | Emerald | Iteration cycles |

## Status States

| Status | Color | Behavior |
|--------|-------|----------|
| `idle` | Type color | No animation |
| `active` | Type color | Subtle pulse |
| `success` | Green | Auto-detected when complete |
| `error` | Red | Manual set for failures |

## Label Formats

| Format | Example |
|--------|---------|
| `percentage` | "50%" |
| `count` | "50/100" |
| `both` | "50/100 (50%)" |
| `none` | (no label) |

## Size Variants

| Size | Height | Text Size | Use Case |
|------|--------|-----------|----------|
| `xs` | 4px | 10px | Very compact, minimal UI |
| `sm` | 6px | 12px | Inline, secondary progress |
| `md` | 8px | 12px | Default, standard use |
| `lg` | 12px | 14px | Prominent, hero displays |

## Accessibility

All progress components include proper ARIA attributes:

```tsx
<div
  role="progressbar"
  aria-valuenow={current}
  aria-valuemin={0}
  aria-valuemax={total}
  aria-label="Progress: 50/100"
  aria-busy={status === "active"}
>
```

For indeterminate progress, `aria-valuenow` is undefined.

## When to Use Each Component

| Scenario | Component | Why |
|----------|-----------|-----|
| Primary progress display | `ProgressBar` | Full features, labels |
| Table cell | `InlineProgressBar` | Fixed width, compact |
| Workflow step | `StepProgressIndicator` | Semantic type mapping |
| File upload list | `ProgressBar` (xs/sm) | Individual file progress |
| Dashboard widget | Both | Overall + details |

## Best Practices

1. **Use semantic types**: Choose the appropriate `progressType` for the operation
2. **Show context**: Use `description` prop to explain what's happening
3. **Handle completion**: Let status auto-detect success, or explicitly set for errors
4. **Consider space**: Use `InlineProgressBar` in constrained layouts
5. **Accessibility**: Provide custom `ariaLabel` when automatic labels aren't descriptive enough
